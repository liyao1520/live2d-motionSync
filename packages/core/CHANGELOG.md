# Changelog

## 2.0.0-alpha.0

Breaking rewrite: one Player for model rendering and audio/lip synchronization. Adds official MotionSync R2 integration, typed session cancellation/FIFO, PCM backpressure, MediaStream capture, ZIP/files import and independent resource cleanup. Uses Untitled 1.3.5 / Pixi 8.20.1. See repository validation matrix for tested and unverified features. No public release has been made.
